# mt-create-plan

Cursor Plan モードに依存せず、GitHub Issue として計画ファイルを新規作成・リファインメントする。from-Issue フロー（既存 Issue を plan 化）もサポートする。

## 実行

`tado-run` を `--workflow ~/.config/opencode/skills/mt-create-plan/workflow.ts` で起動する。
