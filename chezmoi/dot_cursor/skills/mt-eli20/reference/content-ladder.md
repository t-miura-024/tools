# 内容ラダー（content-ladder）

3層と観点表、比喩規律を定義する。手順1・2・5で読む。

## 3層ラダー

- **概要**: 1段落の要旨＋全体図1枚。読後に「何の話か」を言える状態にする。
- **構造**: 構成要素と関係を列挙し、図と1対1に対応させる。読後に「何から成るか」を言える状態にする。
- **詳細＋具体例**: 各要素の動作・手順・数値を具体例つきで掘る。全体→部分→再統合の順で閉じる。
