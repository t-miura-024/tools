# 図の使い分け（figures）

分岐基準と書式を定義する。手順3で読む。CDNの版は [`html-shell.md`](html-shell.md) のピン留め表に従い、ここに版を書かない。

## 分岐基準

- **Mermaid**（既定）: フロー・シーケンス・ガント・クラス・状態遷移。手順・時系列の説明図はすべてこちら。
- **Cytoscape**（条件付き）: 要素間の網・依存関係で、20ノード超またはpan/zoom・選択など操作が必要な時のみ使う。

## Mermaid書式

```html
<pre class="mermaid">flowchart LR
  A[用語は本文と同一にする] --> B[次の状態]</pre>
```

図の前後に1行ずつ、図の読みどころ（どの要素が本文のどこに対応するか）を書く。代替テキストとして図の要点を1文添える。

## Cytoscape書式

使う場合のみ、`<div id="net">` と `elements`（nodes/edges）を本文の用語で定義し、レイアウトは `cose` 既定・層構造のみ `breadthfirst` にする。操作の説明（ドラッグで移動・ホイールで拡大）を1行添える。
