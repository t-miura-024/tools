# mt-eli5

このトピックについて何も知らない5歳児でも分かるように説明してください。
大きな絵と少ない言葉を使ったHTML形式の成果物で説明してください。
CDNにてdaisyUIを利用しCatppucin Mochaのテーマにて、多種多様なコンポーネントや絵文字、アイコンを駆使して表現力豊かに仕上げてください。
成果物は `/tmp/mt-eli5/` 配下に格納し、生成したら `open <file path>` を実行してhtmlファイルを開いてください。
