# mt-propose-capabilities

対象 repo を軽量走査して Capability 軸（新しい能力の獲得）の企画候補を発掘し、ユーザーが選んだ候補を最小構成の draft Issue として起票する。

## 実行

`tado-run` を `--workflow ~/.config/opencode/skills/mt-propose-capabilities/workflow.ts` で起動する。
