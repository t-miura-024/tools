## 目的

normalize-findings が生成した findings.json の must 件数で自律/人相を振り分ける。人への受け渡しは行わない。

## 方針

### 1. findings.json の読み込み

セッションディレクトリの findings.json を読み、counts.must / counts.should と round を確認する

### 2. 自律ループの継続判定

round < 5 で must>0 なら自律ループを継続し、apply-feedback へ戻る。

### 3. 上限到達時の引き継ぎ

round が上限 5 に達したら、残 must / should / want を既存 difit 登録経路で提示し、追加確認なしで await-human-review へ渡す。

### 4. must 解消時の移行

must==0 の場合も difit 登録後に人間レビューへ進む。
