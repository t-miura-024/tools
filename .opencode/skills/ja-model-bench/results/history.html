totalは6問平均(小数第1位)。q別の緑が最高値、赤が最低値。変種・温度・tasks_versionは詳細行に表示。

使い方

推奨起動: bun .opencode/skills/ja-model-bench/tools/serve.ts → ブラウザが自動で開きます。タブを閉じるとサーバも自動終了します。
手動HTTP: cd .opencode/skills/ja-model-bench && python3 -m http.server 8000 → http://localhost:8000/results/history.html
直接 open results/history.html (file://) では history.yml の fetch がブロックされるため、本HTMLは http 経由での閲覧を前提としています。
